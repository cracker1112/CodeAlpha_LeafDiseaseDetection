# 🌿 Leaf Disease Detection — CodeAlpha Internship

## Overview
Plant leaf disease detection using Deep Learning (CNN + Transfer Learning).

## Dataset
PlantVillage Dataset — 15 classes, 20,638 images

## Models Used
| Model       | Train Accuracy | Val Accuracy |
|-------------|---------------|--------------|
| Custom CNN  | 98.10%        | 88.10%       |
| MobileNetV2 | 98.73%        | 93.19%       |

## Technologies
Python, TensorFlow, Keras, OpenCV, Matplotlib, Seaborn, Google Colab

## Results
- MobileNetV2 (Transfer Learning) outperformed Custom CNN
- Best Validation Accuracy: 93.19%
